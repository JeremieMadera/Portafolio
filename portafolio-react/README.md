# Personal Portfolio

This is the source code for my personal portfolio, built with React and Vite. It highlights my profile as a Back-End Developer with Full-Stack capabilities, showcasing my technical skills and selected projects.

## 🚀 Technologies Used
- **Frontend Framework:** React 19 (via Vite)
- **Styling:** CSS Modules
- **Icons:** React Icons

## ⚙️ Features
- **Responsive Design:** Optimized for mobile, tablet, and desktop devices.
- **Component-Based Architecture:** Modular and clean design using React functional components and hooks.
- **Performance Optimized:** Uses `React.memo` and Vite's fast build system for optimal load times.

## 💻 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/JeremieMadera/Portafolio.git
   cd Portafolio/portafolio-react
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
